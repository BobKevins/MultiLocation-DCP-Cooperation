# R2C15：Gao 等人三 DCP/BVPPP 互联拓扑补充验证

本目录采用 Gao et al. (Buildings, 2023, 13, 3096) 的三节点互联规模与
24 h 运行口径，验证当前模型在较小 published topology 下的适用性。

公开论文没有提供可直接复用的完整原始数据，因此本测试仅继承其三节点
全连接拓扑，并使用当前正式算例 DCP1--DCP3 的透明运行参数。该测试不表述为
对 Gao 原文数值的完整复现。

运行入口为 `run_r2c15_gao_3dcp.m`。正式 M3--M5 使用 ADMM；集中式结果只用于
ADMM 误差核验。
