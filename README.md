
## Results / 最终结果

### English

The two summary workbooks in `Results/` are generated from the simulations and are not used as solver inputs:

- `paper_case_figure_data.xlsx`: data for Figs. 5–13, Table 1, and the centralized–ADMM comparison in the main paper;
- `reviewer_response_figure_data.xlsx`: data used in the reviewer responses, including ADMM, Big-M, electricity-price, forecast-error, user-group-number, public-load-trace, and three-DCP extension analyses.

### 中文

`Results/` 中的两份汇总工作簿由仿真运行生成，不作为求解输入：

- `paper_case_figure_data.xlsx`：正文 Fig. 5–13、Table 1 和集中式–ADMM 对比表对应的数据；
- `reviewer_response_figure_data.xlsx`：审稿回复中使用的数据，包括 ADMM、Big-M、电价、预测偏差、用户群组数量、公开负荷以及三 DCP 扩展验证分析。
